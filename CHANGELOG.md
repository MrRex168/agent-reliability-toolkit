# Changelog

All notable changes to this project are documented here.

## [1.0.0] - 2026-09-07

### Added
- Production-ready open-source release focused on local-first AI agent reliability evaluation.
- Repeated evaluation of agent tasks with transparent reliability metrics.
- Text, regex, structured-output, and LLM-as-a-judge evaluation.
- Tool-call and MCP-style trace evaluation.
- Failure classification with actionable categories.
- Regression testing and CI quality gates.
- Optional OpenTelemetry instrumentation.
- SQLite evaluation history and historical comparison.
- Local web dashboard for trends, failures, runs, and comparisons.
- LangChain and LangGraph adapters without framework dependencies in the core package.
- Deterministic unreliable-agent demo for quick validation.

### Release focus
- Developer experience and onboarding.
- Clear 30-second demonstration.
- Stable public API and CLI.
- Repository and contribution hygiene.
- No hosted service, authentication, billing, or cloud infrastructure in the open-source release.
