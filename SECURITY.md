# Security Policy

## Supported versions

Security fixes are applied to the latest release of AI Agent Reliability Toolkit.

## Reporting a vulnerability

Please do not open a public GitHub issue for a suspected security vulnerability.

Instead, use GitHub's private vulnerability reporting for this repository when available. If private reporting is not available, contact the repository maintainer privately through the contact method listed on the maintainer's GitHub profile.

Please include:

- the affected version or commit;
- a clear description of the issue;
- minimal reproduction steps or proof of concept;
- the potential impact;
- any suggested mitigation, if known.

Do not include API keys, credentials, private prompts, customer data, or other secrets in reports or reproduction files.

## Scope

Useful reports include vulnerabilities in the toolkit's Python package, CLI, local dashboard, report/history handling, adapters, and optional integrations.

The toolkit is an engineering evaluation utility. Its reliability score is not a security, safety, compliance, or production-readiness certification.
